# User-supplied anatomy assets

## male-surface.obj

Source archive: `6ndltocgxk74-Male_Base_Mesh_Arshlevon_Sizes.zip`

The archive's included README identifies the original model author as **ARSHLEVON**
and permits use in games, films, and other projects with credit. The mesh is used
as the male anatomical surface in Clinical Edge.

Other supplied archives were inspected but not bundled in this release because
their licence information was absent, their content was unrelated to the body
atlas, or the geometry was not suitable for efficient web delivery without a
separate optimisation pass.
